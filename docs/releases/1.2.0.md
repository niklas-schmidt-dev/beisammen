# beisammen 1.2.0

## App Store — Deutsch

```text
Neu in 1.2.0:
• Einladungen per Code: Jede Einladung hat jetzt einen kurzen Code zum Eintippen, dazu einen QR-Code zum Scannen in der App.
• Profil- und Circle-Bilder lassen sich antippen und in voller Größe ansehen.
• Passwort beim Anmelden und Registrieren ein- und ausblenden; beim Registrieren zeigt die App die Mindestlänge an.
• Einladungslinks funktionieren zuverlässiger aus Messengern heraus.
```

## App Store — English

```text
New in 1.2.0:
• Invite by code: every invitation now comes with a short code to type in and a QR code to scan in the app.
• Tap profile and Circle pictures to view them full-size.
• Show or hide your password when signing in or registering; registration now shows the minimum length.
• Invite links open more reliably from messaging apps.
```
